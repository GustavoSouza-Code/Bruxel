Os diagramas usam Mermaid e aparecem renderizados no GitHub.

A pasta [superpowers](superpowers) guarda as especificações e os planos de implementação de cada funcionalidade, escritos durante o desenvolvimento. Eles registram as decisões de projeto; os documentos acima descrevem o estado final do sistema.

Para instalar e rodar o projeto, veja o [README da raiz](../README.md).
