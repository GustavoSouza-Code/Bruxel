# Instruções para o Claude

## Skills do Superpowers
Sempre que trabalhar neste repositório, use a skill do [Superpowers](https://github.com/obra/superpowers) mais adequada à tarefa, por exemplo:
- `superpowers:brainstorming` antes de criar features ou mudar a UI
- `superpowers:writing-plans` para planejar mudanças maiores
- `superpowers:systematic-debugging` ao investigar bugs
- `superpowers:test-driven-development` ao implementar
- `superpowers:verification-before-completion` antes de dizer que algo está pronto
